## 研究问题

在 MOC 的多阶祖先可见范围内，能否让接收方根据自身状态、消息互补性和通信预算，选择有限的 1–4 跳证据，在减少通信与推理成本的同时保持任务质量？

## 方法候选

主方法候选是接收方状态条件的多阶重要性采样：

1. 以 4 跳作为最大候选范围，不把 3/4 跳全部灌入上下文。
2. 按 hop 建立候选池，支持各层独立预算；远端递减是待检验的配置假设。
3. 用任务、接收方角色、已读消息、拓扑和消息元数据估计候选的增量价值。
4. 对相似但不互补的消息抑制重复，对独立来源的重复证据保留来源信息。
5. 选完后保留作者消息顺序的子序列，只调用一次接收方模型。作者实际是远到近的最短hop/BFS顺序，并非严格全局拓扑序。

## 理论迁移边界

可迁移的是 GraphSAGE/FastGCN/LADIES 一类方法的分层采样、接收节点条件化和预算控制思想；不能把 GNN 线性聚合的无偏估计直接声称适用于有序文本拼接和 LLM 生成。

## 表征候选

第一层基线使用现有 MiniLM 句向量。主模型 hidden-state sketch、KV-derived sketch 是后续可替换的路由表征，不是当前已经验证的核心贡献。当前 Ollama wrapper 只返回文本，使用 KV 需要可导出 hidden/KV 的后端改造。

## 当前边界

2026-10-13 用户确认沿用题目级划分：dev 30题、val 60题、test 254题，共344道不同题。dev/val来自官方dev254的固定hash抽样（前30/随后60），test为官方完整test254。新方法若需要训练路由器，训练数据须另行划分，不能用val/test答案训练。历史六组实验实际只使用dev30和test254；此确认不回改该冻结协议，也不启动新实验。

- 暂不启动新 GPU 实验，也不继续堆一跳/两跳小实验。
- 原六组全图实验、固定回放、成本整合基线和自适应跳数 pilot 均作为历史证据保留，不改写为本方法的验证。
- 3–4 跳候选范围是方法设计假设，不是已经得到性能支持的结论。
- 任何准确率、成本或新颖性结论都必须回到具体协议和原始日志。
