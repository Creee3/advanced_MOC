# SVAMP全弃选诊断（2026-10-16）

本诊断只读取已完整归档并逐SHA核验的训练记录、冻结模型和完整测试记录；不新增模型调用，不修改训练/测试终态、policy或超参数。完整运行审计passed与策略具有有效区分能力是两个不同结论。

40/40训练题有效、80个episode、200个训练标签。逐条读取records/run/training/shard*/questions.jsonl的labels.downstream_delta，统计为：+1共0条，0共198条，-1共2条。单条a动作79零/1负，b动作60零，双条ab动作59零/1负。这里200条是相关动作标签，不是200个独立训练题。80个episode中，不读所测候选消息的empty条件最终答对76次，75个episode的全部候选条件均答对。empty只是对当前接收者所测消息集合的局部干预，其他节点及最终汇总仍运行；不能将其描述为全系统无通信基线。

expected_utility.py将标签转成help=(delta>0)、harm=(delta<0)，分别拟合带截距的加权ridge。由于正标签为零，冻结group_utility_model.json中help头22个系数与截距全部精确为0。预测经裁剪后harm非负，故mean=help-harm必不大于0。expected_set.py以mean-0.02*projected_tokens/1024对候选评分，与净值0的空集比较，只有严格大于0才读消息。因此这一冻结模型无法选择任何非空候选；即使只把成本系数降至0，也不会使非正收益通过严格正值门槛。这不是建议变更参数。

完整测试已记录的supported候选评分：密度0.3共3600条，help全0、mean范围[-0.12752598257269854,0]、net范围[-0.14012363882269854,-0.0008007812500000001]；密度0.7共5100条，help全0、mean范围[-0.07813676312498885,0]、net范围[-0.09073441937498886,-0.0008007812500000001]。均无正mean/net。其余未覆盖角色/hop/集合大小组合按既定support规则拒绝，属于另一条弃选原因。

每密度300题×7个普通节点=2100个决策。密度0.3：300根节点无候选、300无支持动作、1500预测净收益非正；密度0.7：300根节点无候选、1200无支持动作、600预测净收益非正。两种密度都未选单条或双条消息。7个普通agent继续独立生成，FinalRefer仍读取全部最终输出，故不能称完全没有多agent汇总。两密度适配结果相同，稠密适配2400次主模型逻辑调用全部精确缓存命中；仍按923956逻辑token计入比较，不当作零成本。

准确率：稀疏原MOC272/300对适配269/300；稠密271/300对269/300。题目配对并非所有结果相同：稀疏适配改对6、改错9；稠密改对5、改错7。两置信区间均跨零，不证明非劣，也不证明通信普遍无用。稠密逻辑token减少70.08%中，原MOC合并器1531488token被去除，主模型1556620降至923956，不能全归因于消息效用学习。

直接机制已由标签、冻结参数及测试评分闭合验证；为什么本次训练未产生正标签，尚只能提出有限解释：局部empty条件76/80已正确，二元最终对错信号存在饱和；每题仅两个接收者episode，覆盖有限；固定材料、局部干预的训练代理不等于全系统部署目标。当前证据不足以证明任一解释是唯一原因，更不能推断SVAMP所有消息都无用。

运行历史的旧截止中断、随后无截止续未提交，与训练后全弃选是两件事；冻结模型在适配test前已经确定。该批最终1200/1200有效、无重复/invalid、清理和费用审计通过。此前只核对训练完成/标签数量而未及时报告正收益标签缺失，是诊断与告警覆盖的不足。保持原报告与policy，不因完整test结果换样本、重训或调参。
