# v2.1 离线修订与结果

代码与数据接口已修正，但训练内验收未通过。本轮使用原有训练数据完成学习器修订及固定五折验证，新增 LLM 调用/token 均为0；没有启动云端 GPU、重跑论文基准、使用 val 调参或运行 test。没有把模型晋级为部署候选。

## 方法实际改动

候选依旧来自作者 DAG 的最多四跳祖先，保留单条消息与最多两条消息的连接路径组。MiniLM、LADIES 结构特征、正文1024-token预算和成本系数0.02保留。新方法在每个接收节点只决策一次：

\[
\hat S_j=\arg\max_{S\in\{\varnothing\}\cup\mathcal G_j}
\big[\hat\mu_j(S)-0.02\,T(S)/1024\big],\qquad
\hat\mu_j(\varnothing)=0.
\]

\(\hat\mu\) 是固定上游材料、原 Vanilla 下游继续执行时的最终正确性变化预测，不是完整新策略图的真实效用。每条消息原文、作者顺序、普通节点执行与最终汇总保留。没有生成式合并器，亦未实现真实 KV 表示。

这次不再把单次结果残差区间当期望收益置信区间，也不按宽上界/token排序。Bootstrap只描述参数拟合稳定性，不授权“乐观探索”或“安全停止”。无元数据支持的候选弃权；空集合法。没有强制读取或强制成组的配额。

训练只用初始空通信状态下已观测的 empty→A/B/AB，排除条件追加标签；不继续进入 selected_count>=2 等未训练状态。损失按题→episode→动作等权，修正每次拟合和题级bootstrap的加权中心化、截距与题目重抽样次数。此版本是接收方条件化的一次整组选取，尚未验证逐步自适应 hop 轨迹。

## 发现并修正的旧特征错误

冻结 v2 的 collector 给 singleton A/B 也附了整组AB的path，使它们的 connected-path 特征为True；实际生产端 singleton 的path只有自身，特征为False。

本轮176条初始fit动作中，106条singleton受此问题影响。派生数据只更正path、info连接标记及77维向量中对应的唯一标记；奖励、题目、费用、其他76特征及所有原件不变。原始首次OOF结果与源码已保存在 attempt00_stored_features；不把它作为修正后方法效果。数据schema更正协议78faecb提交后，用相同折/参数/三项比较复核一次，没有增加超参搜索。

这个错误影响旧学习器的训练/生产一致性，不改变已经发生的 v2 val 正确数或费用记录。冻结v2的28项源码哈希审查通过。

## 修正后离线结果

仍使用原train35，70个接收方episode、176个初始动作（负33、零126、正17）。固定seed42、5个问题隔离折，所有同题动作在同折；每折标准化和拟合只见其28个训练题。原cal12没有用于本次新模型评价，val/test不参与。三个方案均保留ridge10/bootstrap32，不调整预算或停止阈值。

无信号参照只用于检查学习器，不是新增论文基准。旧v2公式只作实现参照，不能晋级部署。两版新模型均没有优于两个无信号参照，所选动作观测净收益均为负，全部未通过锁定门槛。

## 结论与后续边界

已修正“停止永远不触发”的数学机制、回归截距和训练/生产特征不一致。但这些修复没有使当前MiniLM相似度/角色/拓扑特征可靠地预测证据价值。不能把改成能停，或限制最多两条造成的通信减少，写成学会有效采样。

本轮不继续扩大GPU/val批次，不跑test，也不依此调停止阈值。下一步需要改进效用监督及可辨别证据帮助/损害的表示，先解决训练内可学习性；这不意味着换一个权重就一定能成功。已有对照继续复用。未来独立验证需要另定义未用于设计的数据协议，已看过的val60仍是开发诊断。

数据限制：原训练只为每个接收方选择一组特定祖先对，候选覆盖存在选择偏差；单次生成结果含噪声，且同题动作相关。元数据supported不是语义OOD保证，受限A/B/AB验证也不覆盖所有祖先组合或新全图策略。题级bootstrap区间只作描述，未校正模型选择及交叉验证折间依赖。
