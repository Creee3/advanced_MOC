## 已知限制与错误
- 原 v2 的单次结果残差区间 radius>1，不是期望效用置信区间；所有上界净收益为正，停止不可能。
- 题级 bootstrap 使用未中心化的设计矩阵并固定均值截距，存在实现偏差。
- 训练只有 selected_count=0/1，不能支持无限逐条追加。
- 子代理在预注册前复核了旧 checkpoint 的 cal12 均值决策；此检查仅为已有版本的探索性审计，不能用于新模型选择或作为独立验证。
